## 覆盖情况

| 原检查项 | 修复与验证 |
| --- | --- |
| 学生读取他人私密数据 | API 和 HTML 初始化共用按角色过滤的读取视图；成绩仅在已推送后返回本人数据；反馈、申请、考勤及学习记录按本人过滤；匿名表扬不向其他学生下发作者身份。删除 HTML 内置整班成绩、历史底分及旧账号密码表。学生重传过滤后的数据不会删掉服务器隐藏的记录。 |
| 一体机写入越权 | classroom 会话只读。积分展示、排名、奖品和表扬墙保持可见，去掉登记和归档按钮，后端拒绝所有共享数据变更。登记需使用班干个人账号，老师保留管理权限。 |
| 明文 HTTP | **按用户后续要求保留**。学生使用自己的平板，受管理设备可能无法安装私有根证书，因此未生成、安装或启用自签证书，未切换 HTTPS。HTTP 的传输窃听和篡改风险仍存在。代码仅保留将来可选的 TLS 配置。 |
| 异常记录、页面报错及 HTML 注入 | 新记录使用字段白名单、ID 格式、类型和长度校验；已存在的特殊批次字符串不会再碰撞对象原型；批次、ID、时间等 HTML 输出转义。新增回归覆盖保留字符串、属性注入及错误字段类型。未将原问题夸大为已证实的脚本执行接管。 |
| 重复积分和任意历史补写 | 学生仅可登记服务器当天、本周的积分。按操作者、学生、日期、类别、科目和事由生成服务器业务去重键，换记录 ID 或批次 ID 不能重复同一事项。不同的真实事项仍可登记；历史补录由教师处理。系统仍不能单靠软件证明所描述的课堂事件真实发生。 |
| 学习时长伪造 | 学生不能通过同步直接新增学习记录。服务器持久保存单人计时会话，核算暂停、恢复、跨日时段，并以稳定记录 ID 保证结束重试不重复累计；每日最多 1440 分钟。历史数据保留并标记为历史自报，服务器经过时间不代表已验证的专注程度。 |
| 全量备份放大及磁盘耗尽 | 限制字段、单次新增数量、每日非积分提交量和操作频率。每次写入保存可逆增量，最多每 10 分钟增加一份全量快照；旧证据不删除。状态 32 MiB、归档默认 256 MiB、审计 32 MiB，剩余空间不足时返回 507 并暂停写入。新增恢复脚本通过版本链生成候选文件。 |

另外：限制连接数和读取超时，登录正文最多 4 KiB；认证计算移出全局数据锁并限制并发；改密和登录增加限流，退出清理本系统浏览器存储。新生成的临时密码改为长随机值、7 天有效；本轮未重新发放或修改已有账号密码。

## 后续补充：个人端积分登记入口（v3.0.1）

用户追问登记板块时，发现个人端虽然已有权限判断和操作表单，但导航没有加入积分登记入口。这是前次页面验收未覆盖“有权限班干”的遗漏，现已补齐并上线。

- 有积分登记权限的个人账号显示「积分登记」，普通学生隐藏该入口；一体机仍为「积分展示」。去掉了面向学生的内部权限调试文字。
- 核对线上现有名单：班长、副班长、学习委员的综合积分权限共 4 人，卫生权限 2 人，作业及课堂回答登记权限 15 人（含班委，人数不可直接相加）；有权限的同学均已绑定个人账号。未改动现有职位或账号。
- 合成课代表账号在模拟平板浏览器中通过「学生个人端 → 积分登记 → 作业加分」为另一名合成学生登记 +1，服务器保存成功，actorSid 与操作者署名为课代表本人；普通学生登录后无该入口。
- 新增 4 项导航回归，连同此前 5 项前端安全及 3 项同步检查全部通过。本轮仅更新 HTML，无需重启服务；线上文件摘要与测试文件相同，业务数据和账号文件摘要未变。
- 发布和回退信息见 [personal-entry-result.json](./personal-entry-result.json)。此补充后的 HTML 摘要以该文件为准，原 deployment-result.json 保留首轮发布记录。
