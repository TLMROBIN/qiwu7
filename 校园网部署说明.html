栖梧7班安全部署说明 · v3

当前访问方式

按使用方要求，为兼容学生自有或受管理的平板，保留原内网 HTTP 地址，不启用自签 HTTPS，不要求学生安装证书。HTTP 不提供传输加密；账号、会话和数据仍需依赖可信校园网络环境。应用权限修复不等于消除了传输风险。

部署

Python 3 标准库服务。qiwu7_server.py、qiwu7_security.py、index.html 必须作为同一版本发布。Node 启动器仍调用同一个 Python 服务。

QIWU7_PORT=18090 python3 qiwu7_server.py

敏感数据放在 Web 根目录之外的 qiwu7_private，目录权限 700，文件 600。保留 v2 的 state.json 和 users.json；首次升级会使旧会话失效，需刷新并重新登录，不会重新生成账号或删除已有记录。可通过 QIWU7_PRIVATE_DIR、QIWU7_ALLOWED_HOSTS 和 QIWU7_BIND 配置目录、Host 白名单与监听地址。

权限

教师可管理数据。学生只能读取本人反馈、申请、学习记录、考勤及已推送给本人的成绩/成长报告。公开榜单只发送必要积分数据，奖品兑换的公共扣分总量用于保持排名一致。HTML 中不再内置整班成绩或旧账号密码表。

一体机由教师登录授权后仅展示公开内容；奖品、反馈、申请审核、积分增删均不授予一体机会话。班干登记请使用自己的个人账号，服务器核验身份与职位。学生仅可登记今天、本周的积分；历史补录由教师处理。相同登记事项不能通过换记录 ID 或批次 ID 重复提交，确有第二次独立事项时应填写清楚不同事由。

首次改密要求 12—128 位。新生成的临时密码为长随机值，7 天到期；既有账号密码未在本轮擅自重发。登录、改密与写入均有限流。退出会清除本系统浏览器缓存；请在公用设备使用后退出。

学习计时

服务器持久保存开始、暂停、恢复状态，结束后由服务器按时间段生成记录，跨日分开累计，每日不超过 1440 分钟。客户端同步或导入不能直接增加学习时长。计时依赖联网；服务器经过时间不证明学生一直专注。历史记录保留并标明为历史自报。

容量、备份与恢复

新记录执行字段类型、长度和 ID 校验；学生反馈等文本最多 2000 字，单次最多新增 1000 条，学生同类非积分记录每日最多 50 条。同步写入学生每分钟最多 20 次、教师 60 次，学习计时每分钟最多 30 次。已保存记录的重传不算新增。

当前状态限制 32 MiB，备份归档默认限制 256 MiB（QIWU7_ARCHIVE_MB 可调整），审计日志限制 32 MiB；空间不足或配额用尽时返回 507，暂停写入，提示联系教师。不会自动删除事故证据和旧备份。运维需定期将备份与审计离机归档，再按学校保留制度腾出容量。

新版本每次写入保留可逆增量，最多每 10 分钟新增一份全量快照。已有全量备份继续保留。恢复脚本只创建候选文件，禁止覆盖已有输出：

python3 scripts/restore_backup.py /private/state.json /private/backups 目标版本 /private/recovery-candidate.json

跨越升级前的版本应使用当时的完整快照。恢复业务数据前应由教师审核候选；不得自动把旧网页缓存重新当作权威数据。

以后如需 HTTPS

本轮未配置。代码保留可选 TLS 支持：QIWU7_TLS_CERT、QIWU7_TLS_KEY 指定证书和私钥，QIWU7_REQUIRE_TLS=1 拒绝外部明文请求；TLS 下自动设置 Secure Cookie。若使用反向代理，只能在绑定 loopback 后启用 QIWU7_TRUST_LOOPBACK_PROXY=1。不要在面向学生的监听器上信任客户端自行提交的 X-Forwarded-Proto。
